Connected gateway — ``teranode_gateway.ino``
--------------------------------------------

The production field gateway: device‑id‑first provisioning, MQTT telemetry/state, retained
config/commands, and the edge irrigation control loop (hysteresis, rain‑skip, window, max‑run,
leak detection).

Other sketches
--------------

The remaining sketches are documented in the standalone Doxygen reference (linked below) — they
share global symbol names (``setup``, ``loop``, ``flowISR``) with the gateway, so they are not
re‑embedded here to keep the C++ cross‑reference unambiguous:

* ``schematik_esp32.ino`` — a self‑contained device demo (7‑in‑1 soil + DHT22 + rain + relay, local
  crop table, no cloud). See :doc:`../components/firmware`.
* ``sketch.ino`` — the minimal WiFi + MQTT + sensor template the gateway builds on.
